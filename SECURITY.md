# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues or pull requests.
Instead, use GitHub's private vulnerability reporting for
[0xmfbk/ShieldCTL](https://github.com/0xmfbk/ShieldCTL/security/advisories/new).
Include the affected version, a clear description, reproduction steps or a
minimal proof of concept, and the potential impact.

If private vulnerability reporting is unavailable, contact the repository
maintainer privately through GitHub before sharing any exploit details publicly.

## Response

Reports are investigated privately. After a fix is available, the project will
publish an advisory or release note with the affected versions, fixed version,
and mitigation guidance where appropriate.

## Supported versions

Only the latest release receives security fixes. Users should update to the
latest release after verifying its `SHA256SUMS` file as described in the
[README](./README.md).
